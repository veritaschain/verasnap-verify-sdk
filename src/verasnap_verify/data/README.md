## TSA roots and the VeraSnap apps

The iOS app checks TSA chains against the iOS system trust store at genTime.
This bundle covers the TSAs the apps call (rfc3161.ai.moda, which returns
DigiCert tokens; DigiCert; Sectigo) plus Apple and GlobalSign. FreeTSA's own
root is **not** included: it is not in the Apple or Mozilla stores, so the
apps also show FreeTSA tokens as "chain not trusted" (yellow).

Insurers can replace the bundle with `TrustStore.from_pem(...)`.
